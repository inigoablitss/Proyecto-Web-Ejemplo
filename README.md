Proyecto-Web-Ejemplo

Sitio web estático creado para demostrar flujos de trabajo con Git y GitHub, incluyendo gestión de ramas, Pull Requests y resolución de conflictos de merge.

🚀 Cómo clonar y ejecutar el proyecto localmente

1. Clonar el repositorio:
git clone https://github.com/inigoablitss/Proyecto-Web-Ejemplo.git

2. Acceder a la carpeta del proyecto:
cd Proyecto-Web-Ejemplo

3. Ejecutar el proyecto (dos formas de hacerlo)

   - Abre el archivo index.html directamente en tu navegador web con doble clic.

   - utiliza la extensión Live Server de Visual Studio Code para previsualizarlo en tiempo real.

🌿 Ramas del proyecto:

main: Rama principal y estable de producción. Contiene el código funcional y probado, con todos los merges y conflictos resueltos.

feature-mejora-estilo: Rama dedicada al diseño y presentación visual. En ella se implementaron las mejoras estéticas en styles.css (paleta de colores moderna, contenedor con sombras y tipografía de sistema).
